Points for that decision:

- Zenodo requires a license at deposit, and a public GitHub repository without a license grants no reuse rights.
- Code and data are usually licensed separately. A common pairing is a permissive software license (for example MIT or BSD-3-Clause) for the code in `1_concessionality/code/`, `3_model/`, `4_paper_tables/`, `tools/` and `run_all.py`, and a Creative Commons license for the data and documentation.
- The CGD working-paper front matter permits use and dissemination but excludes commercial reproduction, which corresponds more closely to CC BY-NC 4.0 than to CC BY 4.0.
- Third-party material keeps its own terms (README, section "Data availability and provenance"): the IDA Private Sector Window project list, the extracted fields and short quotations from IFC and MIGA project disclosures, and the text of the World Bank lists of fragile and conflict-affected situations.
